# Throttle iOS — App Store listing copy

Publisher: Christine Martin (TDV6D5L785) · Bundle: com.lorislab.throttle.ios · Min iOS 17

## Positioning (App Store 4.2)
Framed as a **usage-analytics app for your own Claude Code data** that also live-mirrors
from your Mac. History, trends, cap countdown, and threshold alerts remain available
from the last synced snapshot with the Mac off. Interactive terminal input is a separate,
authenticated LAN-only path to the user's Mac; no cloud or off-LAN remote-control relay.

## en-US

**Name** (≤30): `Throttle — Claude Usage`
**Subtitle** (≤30): `Claude Code usage, on iPhone`
**Keywords** (≤100): `claude,claude code,usage,tokens,ai,cost,meter,cockpit,anthropic,developer,limit,quota`
**Promotional text** (≤170): `See your Claude Code 5-hour and 7-day usage from the last private iCloud sync, with live sessions when your Mac is on the same local network.`

**Description**
Throttle mirrors your Mac's Claude Code usage to your iPhone through your private iCloud database. When both devices are on the same local network, it can also show live sessions directly from your Mac. Throttle does not use a LorisLabs relay or analytics service.

WHAT YOU SEE
• The binding window — your 5-hour session and 7-day limits as a single clear gauge, with a live countdown to the next reset.
• Your sessions — Claude Code projects published by your Mac, including state (working, waiting, rate-limited, hibernated), model, cost and tokens.
• History & trends — 24h / 7d / 30d utilization and cost views from the latest synchronized data. Saved trends remain visible when your Mac is off.
• Optional LAN terminal — on the same local network only. Input starts locked, requires Face ID or the device passcode, and relocks after inactivity or when the app leaves the foreground.

ALERTS & GLANCE
• Home Screen and Lock Screen widgets show your usage at a glance.
• Optional notifications warn you at 80% and 95% — before you hit the wall.

PRIVATE BY DESIGN
Usage snapshots are stored in your private iCloud database. Live session and terminal traffic travels directly over your local network to your Mac. Throttle for iPhone is a companion to Throttle for Mac (a separate download at lorislab.fr/throttle/).

**What's New**
`A safer companion connection: live terminal input is now limited to the same local network, starts locked, and relocks automatically. This update also improves reliability and privacy declarations.`

**App Review notes**
`Throttle's usage/history surfaces read the user's private CloudKit data. The optional interactive terminal is available only when the user's own Mac is discovered on the same LAN through Bonjour. It has no cloud or off-LAN remote-control fallback, starts read-only, requires device-owner authentication before input, and relocks on inactivity/background.`

## fr-FR

**Name** (≤30): `Throttle — Usage Claude`
**Subtitle** (≤30): `Votre usage Claude Code`
**Keywords** (≤100): `claude,claude code,usage,tokens,ia,coût,jauge,cockpit,anthropic,développeur,limite,quota`
**Promotional text** (≤170): `Consultez votre usage Claude Code (5 h et 7 j) depuis la dernière synchro iCloud privée, avec les sessions en direct sur le même réseau local.`

**Description**
Throttle reflète l'usage Claude Code de votre Mac sur votre iPhone via votre base iCloud privée. Lorsque les deux appareils sont sur le même réseau local, l'app peut aussi afficher directement les sessions actives du Mac. Throttle n'utilise aucun relais LorisLabs ni service d'analytics.

CE QUE VOUS VOYEZ
• La fenêtre déterminante — vos limites de session (5 h) et hebdomadaire (7 j) réunies en une jauge claire, avec un compte à rebours jusqu'à la prochaine réinitialisation.
• Vos sessions — les projets Claude Code publiés par votre Mac, avec leur état (actif, en attente, limité, en veille), le modèle, le coût et les tokens.
• Historique & tendances — vues 24 h / 7 j / 30 j de l'utilisation et du coût à partir des dernières données synchronisées. Les tendances enregistrées restent visibles lorsque le Mac est éteint.
• Terminal local optionnel — uniquement sur le même réseau local. La saisie commence verrouillée, exige Face ID ou le code de l'appareil, puis se reverrouille après inactivité ou passage en arrière-plan.

ALERTES & COUP D'ŒIL
• Widgets écran d'accueil et écran verrouillé pour un aperçu instantané.
• Notifications optionnelles à 80 % et 95 % — avant de toucher la limite.

PRIVÉ PAR CONCEPTION
Les instantanés d'usage sont stockés dans votre base iCloud privée. Les sessions en direct et le terminal communiquent directement avec votre Mac sur le réseau local. Throttle pour iPhone accompagne Throttle pour Mac (téléchargement séparé sur lorislab.fr/throttle/).

**Nouveautés**
`Connexion compagnon renforcée : le terminal en direct est désormais limité au même réseau local, démarre verrouillé et se reverrouille automatiquement. Cette version améliore aussi la fiabilité et les déclarations de confidentialité.`
