Fewer tokens

Optimizers that cut what you spend.

Output styles
One-click reply styles — Concise, or aggressive "Caveman" compression — applied to every claude session, terminal and Cockpit. Requests shorter replies; response quality and savings depend on the model and task.
settings.json hardening
Deterministic one-click fixes — deny blind reads of .env, node_modules and build output, set a cost-sane default model — each a reviewable diff, backed up before any change.
Image → text on dropNew
Drop a screenshot into a Cockpit session and Throttle OCRs it locally to text — token savings depend on the image and model. OCR can omit visual information. Hold ⌥ to keep it as an image.
Context trimmer
Strips re-charged base64 screenshots from past transcripts so --resume reloads light — reversible, the original backed up, the active session untouched.
Searchable session memoryNew
Search your past claude sessions for context the window has lost — a dedicated Search window, plus an opt-in MCP server so Claude can search its own history too. On-device semantic search can find related terms; results depend on the indexed content.
MCP manager & memory hygieneNew
Move any MCP server between Global, project-local and the shareable .mcp.json, enable, disable, add or remove one — each file backed up first. Zombie servers flagged with a real list_tools handshake; MEMORY.md indexed past Claude Code's 200-line / 25 KB auto-load cap.
Autopilot
Keeps your Claude Code setup optimized system-wide, by default — concise replies and a live usage statusline on, dead memory from deleted projects archived. Review recorded changes and the restore options available for each action. External effects are not automatically undone.
Compress command output
A PostToolUse hook strips ANSI, dedups and trims verbose CLI output before Claude sees it — a green test run collapses to a line, retains detected errors. Review compressed output when diagnosing a failure; savings depend on the command.
Cache-bust attributionNew
Shows why your prompt cache is being re-written — model swaps vs prefix churn — to help investigate repeated context charges. Computed on-device from your own transcripts.

Local supervision, explicit connections and control.

Throttle reads local session data and stores project history on your Mac. Processing follows the provider you select. Optional model providers, remote sessions and CloudKit can receive data; license activation and update checks contact their services. Project commands run with your macOS account permissions and are intended for trusted projects. Uninstalling the app does not automatically erase stored data or undo external effects. See the privacy policy for data flows and retention.
